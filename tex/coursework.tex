\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

This project plan addresses the problem of domain shift in computer vision, specifically focusing on the transition
from high-quality synthetic and studio-grade image data to real-world user-generated photographs with variable quality.
The work aims to develop a unified data collection and annotation protocol, implement baseline classification and
object detection models (ResNet, YOLOv8, Vision Transformer), and systematically evaluate model robustness under
diverse environmental factors including noise, brightness variations, shadows, blur, and viewpoint changes. A
comparative analysis will be conducted to assess model performance degradation across domains. The planned deliverables
include a curated dataset, a unified repository of experimental results, and a course work detailing the methodology
and findings. The expected outcomes will contribute to understanding domain adaptation challenges and provide
benchmarks for robust vision system development.

\section{Introduction}
\label{sec:introduction}

\subsection{Problem Relevance}
Computer vision models often fail when deployed in real-world conditions due to the domain gap between controlled
training data (synthetic/studio) and unpredictable user-generated content. This project systematically analyses the
synthetic-to-real shift, focusing on robustness against common image quality degradations.

\subsection{Problem Statement}
The research question is: \textit{To what extent do state-of-the-art vision models degrade when applied to data with
	realistic environmental distortions, and how can this degradation be measured?}

\subsection{Project Objectives}
\begin{enumerate}
	\item Develop a protocol for cross-domain robustness studies.
	\item Implement baseline models (ResNet, ViT, YOLOv8) on high-quality source data.
	\item Simulate environmental degradations to create target domain variants.
	\item Evaluate and compare model performance across domains.
	\item Create a public benchmark dataset and code repository.
	\item Document methodology and results in a course work.
\end{enumerate}

\subsection{Task Distribution}
Individual project.

\section{Literature Review}
\label{sec:litreview}

Domain adaptation methods include domain-invariant feature learning \cite{tzeng2017adversarial} and adversarial
training \cite{ganin2016domain}. Synthetic-to-real transfer often uses simulation or generative models
\cite{richter2016playing, shrivastava2017learning}. Vision Transformers \cite{dosovitskiy2020image} show strong
performance but their robustness to quality degradation is understudied. Benchmarks like ImageNet-C
\cite{hendrycks2019benchmarking} test corruption robustness but not specifically synthetic-to-real shift with
user-photography artifacts.

\section{Detailed Work Plan}
\label{sec:workplan}
The project is divided into five sequential phases.

\subsection{Phase 1: Methods Research \& Dataset Search}
\begin{itemize}
	\item Review methods for domain adaptation and domain transitions.
	\item Indentify suitable datasets with source domain (synthetic/studio) and target domain (user-generated).
	\item Analyze domain gaps and document key challenges.
\end{itemize}

\subsection{Phase 2: Model Implementation}
\begin{itemize}
	\item Fine-tune ResNet-50 and ViT-B/16 for classification on source domain.
	\item Train YOLOv8s for detection on source domain.
	\item Establish baseline metrics on validation set.
\end{itemize}

\subsection{Phase 3: Degradation Simulation}
\begin{itemize}
	\item Implement degradation pipelines:
	      \begin{itemize}
		      \item Gaussian noise, brightness/contrast changes.
		      \item Synthetic shadows, blur, perspective transforms.
	      \end{itemize}
	\item Generate degraded test sets with controlled severity.
\end{itemize}

\subsection{Phase 4: Experiments and Analysis}
\begin{itemize}
	\item Evaluate all models on: pristine source, original target, and degraded subsets.
	\item Analyze performance drops per model and per degradation factor.
	\item Compare CNN, Transformer and hybrid (CNN + Transformer) robustness.
\end{itemize}

\subsection{Phase 5: Repository and Reporting}
\begin{itemize}
	\item Create public GitHub repository with code and documentation.
	\item Write final project report.
\end{itemize}

\section{Expected Outcomes and Significance}
\label{sec:expected}

\subsection{Expected Outcomes}
\begin{enumerate}
	\item Three benchmark models (ResNet-50, ViT-B/16, YOLOv8s) fine-tuned and evaluated on source domain data.
	\item A degradation pipeline to simulate real-world image corruptions (noise, blur, shadows, etc.) with adjustable severity.
	\item Quantitative results showing how each model performs on:
	      \begin{itemize}
		      \item Clean source domain data
		      \item Real target domain data
		      \item Synthetically degraded data
	      \end{itemize}
	\item Comparative analysis of CNN, Transformer, and hybrid model robustness to domain shifts and image corruptions.
	\item Public GitHub repository with all code, documentation, and pre-trained models.
	\item Final course project report documenting methodology, experiments, and findings.
\end{enumerate}

\subsection{Significance}
\begin{itemize}
	\item \textbf{Scientific:} Systematic comparison of modern architectures under realistic domain shift.
	\item \textbf{Practical:} Guides model selection for unpredictable input quality.
	\item \textbf{Open Science:} Fully reproducible benchmark for future research.
\end{itemize}

\subsection{Risks and Mitigation}
\begin{itemize}
	\item \textbf{Insufficient data:} Use multiple public datasets and pre-trained models.
	\item \textbf{Scope too large:} Prioritize core degradations; modular pipeline.
	\item \textbf{Annotation effort:} Focus on fewer object categories.
\end{itemize}
